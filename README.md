# AIM: STUDY OF WHILE LOOP


# THEORY:

The aim of this experiment is to study and understand the working of the while loop in Python.
A while loop is a control structure that repeatedly executes a block of code as long as a given condition remains true.
It is mainly used when the number of iterations is not fixed and depends on a condition.

In this experiment, different programs were implemented to understand how the while loop works in various situations.
# Basic While Loop Execution:
The loop was used to print numbers from 1 to 5. This helped in understanding how initialization, condition checking, and incrementing work together inside a while loop.

# Generalized Program (1 to N):
A user-defined value of N was taken as input, and numbers were printed from 1 to N. This showed how loops can work dynamically based on user input.

# Factorial of a Number:
The factorial program demonstrated how repeated multiplication can be performed using a while loop until the condition becomes false.

# Fibonacci Series:
The Fibonacci sequence was generated in two ways:
Based on number of terms
Based on a limit value
This helped in understanding variable updating and multiple variable handling inside a loop.

# Reverse of a Number:
The digits of a number were extracted using modulus and division operations inside the loop to reverse the number.

# Palindrome Check (Number and String):
The program checked whether a number or string is a palindrome by comparing it with its reverse. This demonstrated logical comparison and condition checking.

# Counting Digits:
The number of digits in a given number was calculated using repeated division inside a while loop.

# Break Statement:
The break statement was used to immediately exit the loop when a specific condition was satisfied.

# Continue Statement:
The continue statement was used to skip certain iterations (for example, skipping even numbers and printing only odd numbers).

# Searching an Element in a List:
A while loop was used to search for an element in a list, demonstrating practical use of looping and condition checking.

Overall, this experiment explains how the while loop can be applied in different logical problems such as
mathematical calculations, sequence generation, number manipulation, and searching operations.
